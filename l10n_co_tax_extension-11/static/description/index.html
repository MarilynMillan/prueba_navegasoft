Actualización funcional de retención por umbral

Esta actualización incorpora un modo global opcional para evaluar el umbral de retención con la suma de líneas aplicables, manteniendo el modo por línea como comportamiento base.

Novedades agregadas

  • Configuración global en ajustes de contabilidad: Usar base global aplicable para retención.
  • Campo en producto (tab Contabilidad): Aplica al umbral de retención.
  • Líneas negativas: ajustan la base global y no disparan retención en la propia línea.
  • Recalculo automático al guardar en facturas, ventas y compras.
  • Botón Calcular Impuestos en factura con recálculo forzado consistente.

Reglas funcionales

Escenario Comportamiento
Modo global desactivado Umbral evaluado por línea (comportamiento actual).
Modo global activado Umbral evaluado sobre la suma de líneas aplicables.
Línea no aplicable No participa en base global ni recibe retención.
Línea negativa Reduce base global y no aplica retención en esa línea.
