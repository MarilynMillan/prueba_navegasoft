Propósito principal

Este módulo controla y agrupa líneas de factura de cliente para escenarios DIAN, limitando la cantidad de productos/variantes diferentes y asegurando consistencia entre PDF, XML UBL DIAN y validación previa a envío/impresión.

Configuración requerida

  1. Ir a Contabilidad > Configuración > Ajustes.
  2. Configurar Alcance para líneas agrupadas, Diarios con agrupación, Agrupar por producto y Límite de líneas agrupadas para facturas.
  3. Si el alcance es por diario, seleccionar diarios de venta aplicables.

Guía de usuario

  1. Crear o editar una factura de cliente.
  2. Agregar líneas de producto.
  3. El total agrupado se calcula solo cuando aplica el alcance DIAN (global o por diario configurado).
  4. La agrupación puede ser por variante o por plantilla, según configuración.
  5. Si supera el límite, se bloquea impresión/envío.
  6. La vista previa, el PDF y el XML UBL DIAN usan líneas agrupadas.
