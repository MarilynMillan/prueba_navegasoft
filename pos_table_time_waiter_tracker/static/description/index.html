POS Restaurant Table Show Seated Time | Waiter Name | Order Amount

This module enhances restaurant management in Odoo POS by adding table tracking features. It monitors table occupancy duration, show waiter names on order tables, displays live order amounts, and provides actionable insights directly on the floor plan. Designed for busy restaurants, it optimizes table turnover and staff coordination.

Features
  • Table Timer: Automatically starts when an order is submitted.
  • Table Timer: Stops when payment is completed.
  • Table Timer: Displays live occupancy duration (HH:MM:SS) on the table icon.
  • Waiter Assignment: Auto-captures the cashier/waiter’s name when placing an order.
  • Waiter Assignment: Shows the assigned waiter on the table icon.
  • Live Order Amount : Displays the current order’s total amount on the table.
  • Live Order Amount : Updates dynamically as items are added.
  • Automatic Table Release: Releases the table seated time and waiter a after payment.
  • Configurable: Enable/disable via POS settings
  • Support Community and Enterprise Editions
Usage Instructions
  • Enable Feature: Go to POS Settings → Restaurant → Enable Table Time Counter.
  • Start Order: Timer/waiter/amount automatically populate when submitting an order.
  • Monitor Floor Plan: Tables show: Timer (e.g., 02:15:30) & Waiter name (e.g., Maria) and Amount (e.g., $42.50).
  • View Order Details: Check Start Time, End Time, Duration, and Waiter in the order form.
