# POS Combo Products

POS Combo Products allows you to create product combos in Odoo POS. You can create and view POS combo groups and POS combo products. Moreover, you can configure between grid and list view to select items. Also, the module allows category and combo configuration in the Odoo backend.

---

## Key Features

- Combo Product Selection: When a combo product is selected, a pop-up window opens where different categories of products can be chosen.

- Backend Configuration: Admins can configure how many categories will be available in the pop-up and the products shown in each category.

- Dynamic Pricing: The final price of the combo product is automatically calculated based on the products selected from each category.

- Customizable Product View: The product list can be displayed in either List View or Grid View based on the backend configuration.

- Easy Management: Configure combo categories and product options through the backend interface, making it easy to update and manage combo products.

---

## How It Works

1. Go to **Combo Product Configuration > Combo Categories**.
2. Here Different categories are created and edited which are choosen in combo products.
3. Go to **Combo Product Configuration > Category Options**..
4. Here the products are created and edited which are selected in categories.
5. Go to **POS configuration > POS Combo Products > Popup View**.
6. Here the popup view is choosen. Grid/List
7. Differnt Category is also made for the combo products. So that on selcting the combo products category we can filter all the combo products in the POS.
8. On clicking any combo product, a pop up will open in which there are different sections of category.
9. From which the products are selected.
10. According to the product choosen the final price of the product is computed.
11. All the choosen products from the popup are shown in the orderline and also in the receipt.
12. Once the products are selected from the popup and the orderline is created, it can be edited on clicking the info icon in the orderline.
